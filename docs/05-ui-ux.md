# UI & UX Philosophy

## Design System
- Theme Engine with 6 rich color palettes (Golden Arcade, Cyber Neon, Cozy Chocolate, Emerald Growth, Sunset Glow, Midnight Royal).
- Glassmorphism containers with vibrant accents and modern typography ('Outfit' & 'Inter').

---

## Home Dashboard
- **Coin Vault / Treasury Jar**: Dynamic visual progress container showing total balance and coins earned today.
- **Quick Habit Grid**: Tactile 1-tap habit buttons displaying `+N 🪙` badge.
- **Flying Coin Micro-Animation**: Coins float up into the Vault on tap.
- **Reward Store Quick Shelf**: Featured store items ready to unlock.

---

## Reward Store Page
- Grid of redeemable rewards with cover images/icons, coin price badges, and purchase buttons.
- Full Store Item Manager to Add, Edit, Delete rewards, with custom image file upload or preset selection.

---

## Celebration FX
- Particle celebrations on store redemption and habit goals:
  - **Confetti Explosion**
  - **Golden Coin Shower**
  - **Fireworks Sparkle**
  - **Starburst**
